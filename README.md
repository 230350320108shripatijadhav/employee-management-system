# Employee Management System

## 📌 Project Description
Employee Management System ek Spring Boot based application hai jisme hum employee data manage kar sakte hain jaise:
- Add Employee
- Update Employee
- Delete Employee
- View Employee List
- Send Email Notifications
- Generate Excel Reports

Ye project mainly backend REST API based system hai.

---

## 🚀 Features
- ✅ Employee CRUD Operations (Create, Read, Update, Delete)
- ✅ Email Sending using JavaMailSender
- ✅ Excel Report Generation (Apache POI)
- ✅ Scheduler for automatic email sending
- ✅ REST APIs testing using Postman

---

## 🛠️ Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL Database
- Maven
- Apache POI (Excel)
- JavaMailSender (Email)
- Postman (API Testing)
